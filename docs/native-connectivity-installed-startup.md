# Normal Main static startup entry

The normal Main accepts four absolute paths: control socket, protected
startup profile, admission journal and worker executable. Its first Rust
statement captures BOOTTIME and checked-adds the existing three-second startup
budget, before argument collection and profile/listener work. The one cutoff
passes unchanged through main_service::run, Service and typed WorkerStart.
There is no fifth-argument or configurable-timeout path. Receive/action durations,
worker bootstrap, capability reduction and retirement are unchanged.

The actual host baseline at88842e2 now qualifies paired RED with the same
frozen consumer. Four paths naturally return InvalidInput with no admission.
The five-argument witness actually enters startup: the normal worker fails
capability reduction with NET_ADMIN absent, Main becomes cap0, retains its
original supplied cutoff, and closes normally after Stop. Both consumer desired
assertions fail after owned closure; both receipts qualify observation and ECHILD.
This establishes the CLI gap rather than a loader/profile or privilege failure.

The same frozen consumers now pass on the isolated candidate based on256c553.
The four-path case observes real owned startup, worker capability failure,
cap0 Main and normal Stop0. Its reported cutoff minus three seconds lies within
the parent's observed entry interval. The old fifth argument instead returns1
naturally with InvalidInput before admission. Both consumers exit0 after actual
Main wait/PIPE EOF, retained namespace closure and ECHILD. The interval verifies
derivation; first-statement placement is source evidence, not an initialization-delay
runtime result. [Hash-only evidence](evidence/native-connectivity-installed-startup.json)
retains the separate RED/GREEN receipts and unchanged consumer hashes.

Formatting, strict Clippy,53 host tests and all seven FIFO/wire controls pass.
Normal host/ARM release providers and the ARM library-test executable compile;
the ARM tests are not executed. The corrected supervisor comment is part of the
published256c553 base; the only new production behavior is the Main entry.

Nine public launch sites now pass four paths. The current Main-idle controller
now passes its three-case regression; the other eight current variants have not
run. Old evidence keeps its original hashes and immutable Git source cohorts.
The first-retirement variant explicitly checks the derived three-second entry
interval instead of equality with parent W. Other callers retain their original
fixture startup observation, action and retirement limits and label the
observation limit separately from Main's cutoff. No old-CLI fallback exists.
[Current launcher/helper bindings](../tools/native-connectivity-worker/current-main-launchers.json)
and the separately prepared Main-idle source dataset identify current inputs;

startup/observation evidence, with no connected-address or packet operation.
