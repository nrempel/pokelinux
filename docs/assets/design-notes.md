# README artwork

The banner is generated conceptual artwork, not a device screenshot. Built-in image generation was used. Three directions were explored: terminal grid, engineering workbench and pocket desktop window. Terminal grid was selected for readable hierarchy and a clear connection to the Linux software stack. Workbench looked like generic product photography; pocket desktop suggested a more finished device than exists.

Final prompt: Wide 3:1 GitHub README banner. Large title Pokélinux, subtitle Independent mobile Linux research. Status PIXEL FIRST / OMARCHY INTEGRATION / IN DEVELOPMENT. Original terminal-grid pixel phone illustration. Tokyo Night navy, blue, mint, lavender and off-white. No official logos or game imagery. Conceptual art, not a working-device screenshot.

Architecture diagrams are editable Mermaid in README.md. The dark and light theme images are unedited captures from native-vm-09, an Arch ARM VM test with the bridge unavailable. They are evidence of UI/theme behavior only.
