# Native typed add-PDN transport

`TransportSession::prepare_add_pdn` connects the bounded typed encoder to the
current owner's request lifecycle, immutable selected slot and owned request
worker. A fixed ignored library test qualifies one complete663-byte request105
packet through actual generic ARM kernel Binder to an independent public
synthetic peer. It adds no APN context writer, registration readiness, final
response meaning, installed command ingress or phone result.

The [original SDK codec](native-ims-add-pdn.md) and
[pure native encoder](native-ims-add-pdn-native.md) retain separate evidence.

host suite78passed/0failed/8ignored (library67passed/2ignored). The new ARM test is
ignored in that host suite and is selected explicitly in each fresh VM.

raw callback, a joined registration worker and full original663-byte encoding.

production API. Fixture-only control128 clears its capture table, preserving

## Closure and remaining gates

builds and four VMs. Actual test waits and EOF precede the same original2s Rust
cleanup cutoff. Setup10s/oracle20s/session30s are never renewed. Capture epochs and

are checked after fixture waits and EOF, rejecting late/duplicate/refused capture.
Manager is exact pidfd-killed/waited9 in every case. All16 tracked guest children
have actual waits and bounded EOF; no failure-only disposal qualifies. Docker
CLI0, live exact CID then fresh absence, same daemon and unchanged inputs close
each run. The finalizer references those existing backing-image closure checks
without rehashing the large disk or duplicating the447-file SDK inventory.

This is synthetic Binder transport, not APN acquisition or accepted protocol
behavior. Qualified response identity/meaning, durable installed command ingress,
current permissions/provider/subscription/worker incarnation and owned network
fields remain required before installed modem dispatch. The backend still targets Samsung
radioExternal; replacement of its vendor/modem-facing userspace provider remains
required by the final native Rust architecture. Remote cleanup, safe retry/reset,
carrier/IMS operation and Pixel hardware remain open. The VM kernel is
7.1.6-1-aarch64-ARCH; this selection adds no matched Google-kernel execution,
actual suspend, installed app or UI result. No physical phone was accessed.
