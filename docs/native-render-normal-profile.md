## First normal startup baseline

A later baseline invokes that exact NORMAL main and AQ cohort. It answers126
kernel-peer-authenticated public snapshots: one STARTING/stage8 reply, followed
by125 STOPPING/stage5 replies. Every reply reports a live Busy worker, readiness
false, zero outputs and no public startup error. Stage5 means bootstrap returned;
it does not identify a blocked native call. Zero reported outputs establish no
accepted discovery.

The first STOPPING snapshot is observed at9.078366928s, approximately0.284s
after the8.794283644s startup generation, before the advertised28.794283644s
deadline. STOPPING remains observed beyond that deadline. These are sample
times, not the transition timestamp; the early-stop cause is **UNKNOWN**.
The maximum socket request takes10,487,716ns; the126 replies total57,579 bytes.
No client or witness executes, and no protocol-global, SHM capture or frame
result is qualified.

The original generic `AssertionError`, `UNQUALIFIED_EARLIEST_GATE` and
`FIXTURE_OR_PROCESS_SETUP` classification remain preserved. This closed but
unmet readiness gate is not a semantic production RED or functional PASS.
All37 direct waits and44 PIPE EOFs close within original bounds, alongside one
separate QMP socket EOF and126 public-response EOFs. Main is disposed by actual
SIGKILL/wait-9 and PIPE EOF, with owned descendants closed; that is no proof of
native retirement or Rust join. QEMU/CLI wait0, same-daemon exact-container
absence and unchanged locked inputs qualify process closure separately.
The cohort binds the bounded execution/controller/case graph and independent
review; raw replies, logs and private paths remain unpublished.

AQ, its headers/SDK and main must use a consistent normal profile and matching DRM class layout;
a test-profile main or SDK cannot stand in for the normal pair. The guard's
successful empty normal translation unit does not establish that ABI or loader
composition. Normal startup, complete client-to-frame/worker output, native
retirement, Source acceptance/timing, current ARM and physical phone gates
remain unqualified. The earlier [CPU texture component](native-render-cpu-texture.md)
and [startup-custody checkpoint](native-render-owned-startup.md) retain their
separate evidence boundaries. No physical phone was accessed.
