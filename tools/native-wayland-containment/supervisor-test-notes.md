build4 against the actual original ARM compositor. After original context ready,
SIGSTOP must produce an actual kernel State T. Status and stop are each observed
against an unchanged 250ms BOOTTIME budget and must fail the desired responsive

missing future supervisor is not itself executed and is not a behavioral RED.

The future GREEN intent is an independent native Root parent with one authenticated
bounded private seqpacket SDK child; no SDK dispatch in the parent. Its initial

until_ns, memory_bytes=134217728 and fd_limit=64. /proc child limits must confirm
128MiB address-space, FD64 and zero core limits. Child parent-death policy is kill.

Additional independent epochs test actual original source death and native parent
death while its SDK child is held. Resource and reap observations use real /proc,
pidfds and wait ownership; no mock completion qualifies these cases. Current
unexecuted GREEN intent is not supervision evidence.

The original protocol/Qt selected guest and probe remain unchanged. Existing VM
