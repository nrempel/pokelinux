# Rust session reconciliation boundary

The production policy belongs in Rust: immediate authority invalidation, bounded
ordered CHANGE custody, worker scheduling, suspend-aware deadlines and acceptance
of refreshed discovery through the latest invalidation. C++ connects genuine
Aquamarine callbacks and native objects to that boundary. The graphical stack
still contains substantial upstream C++; this package does not complete its Rust
migration or qualify a phone.

`session-reconcile-public-api.cpp` and `session_reconcile_epoch.py` are the exact
frozen structural RED target/classifier. The actual existing-header control
compiles without diagnostics; this target reports precisely four missing ABI2
functions. This is a syntax boundary, without a linked worker or native result.

`device_change_recovery_case.py`, `device_change_recovery_oracle.py` and
`CONTRACT.md` are the frozen real NORMAL owner/public-socket target. The actual
baseline observes genuine STARTING/stage8 followed by device-change Stop before
Ready and the original20s cutoff. The GREEN predicate additionally requires
real Rust acceptance and ten reconciliation watermarks; Ready alone cannot pass.
These sources use the existing first-Stop helpers and reviewed owned controller,
input admission and custody helpers. They are not a standalone VM runner.

`functional_oracle.py` checks the independent real C++ to Rust integration
consumer in `native-render/tests/session_reconcile_ffi.cpp`. Its callbacks are
authored CPU fixtures. The six groups cover immediate old-ticket invalidation,
32-entry capacity, three queued changes without an extra control wake, immutable
metadata, latest-only Ready, fixed real deadlines, late callback refusal and
retained sealed work. Actual native AQ reconciliation remains a separate gate.

Only original source and compact hash-only provenance are suitable for this
public package. Raw private receipts, binaries, vendor inputs and credentials
are excluded. Implementation and test results are recorded in the affected
native-render documentation when they actually qualify.

`owned-startup-session-reconcile.patch` is the original two-file native adapter
change. Apply it after the first-Stop package to the exact before hashes in
`source-cohort.json`; both after hashes must match. The matching NORMAL build
passes with the new sole Rust provider. The actual native recovery attempt
remains unavailable at format/modifier corroboration; see the
[checkpoint](../../../docs/native-render-session-reconciliation.md). A compiled
adapter and CPU GREEN do not qualify real native recovery.
