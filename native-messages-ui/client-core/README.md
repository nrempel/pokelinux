# Messages client engine

This crate owns the complete app-local Messages request, parser, model, paging, generation, scheduling, deadline, notification FIFO/ACK and shutdown verdict. The C header is the exact independently frozen12-export ABI. Qt retains the real QThread, credential-checked SEQPACKET transport, received-rights closure, queued invocation, actual native wait and final JSON-to-QVariant presentation. There is no Rust OS thread or service/lifecycle permission change.

Safe engine, model, protocol and layout modules forbid unsafe code. Only the narrow FFI pointer boundary and fallible libc CLOCK_BOOTTIME helper use unsafe. This deliberately preserves interception by the existing native clock wrappers. Request and Stop arithmetic is checked; no caller-injected clock exists. Unknown item keys and the last duplicate-key items array retain their original bytes; Accepted pages retain unknown fields within the finite JSON numeric domain measured at the Qt projection boundary; Rust refuses numeric overflow before that mechanical conversion. Required integral fields are validated as exact decimal numbers. Unicode scalar strings and exact lowercase32-byte IDs follow the authored contract.

The notification acknowledgement lives independently of the FIFO: GUI delivery or generation changes do not erase it, duplicate NOTIFY is refused, and ACK/CLOSE/delivery never renew the completion wake. Stop cancels pending notifications but retains every issued-connect descriptor-close obligation. An actual successful native wait plus worker exit takes precedence over uncertain or late time.

An internal clock/checked-time failure queues a generation-scoped unavailable event with absent future wake encoded as0, then requires native CLOSE/EXIT with no implicit retry. Initial native CONNECT is clock-ungated; no SEND is admitted without a valid sample. This terminal error does not consume the UI Stop budget; actual Stop still establishes that once-only ownership disposition. Actual invokeMethod(false) calls Stop, never acknowledges queueing, closes the native fd and exits.

`tests/client-functional.cpp` is the frozen independent nine-group consumer, with only its include renamed to the production header. Root owns actual execution of that consumer and the unchanged7 worker,40 current-Qt,29 appearance, UID/argv and installed-QML controls. They establish distinct component and actual Qt edges; no hardware or renderer result follows from source.
